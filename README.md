# vscode-codeskills

授信报告历史兼容入口。唯一业务维护源为 [Finish-work-early 工作技能区](https://github.com/Daisyhu668/Finish-work-early/tree/main/skills)，当前完整授信技能见 [shouxin-report](https://github.com/Daisyhu668/Finish-work-early/tree/main/skills/shouxin-report)。

本仓库 `shouxin-report/` 保留触发入口及客户端元数据，正文仅导航到主源，不再独立维护报告规则。已有安装仍可从旧路径识别入口；执行前必须读取主源与必要依赖。

新环境优先取得 Finish-work-early 的完整 `skills/` 目录，再按其 README、catalog 和路由按需加载。不要只复制一个 SKILL.md，也不要假设安装脚本位于某台电脑的固定绝对路径。安装与当前会话实际可用性分别核验。

Home Repo 为用户跨项目导航；银行技能、脚本和授权原模板继续在 FWE 主库维护。保留原模板，按材料作真实风险判断，未知字段不编造。
